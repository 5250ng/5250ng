  5250script Language Reference — Prompt for Script Generation                                                                                                                                                                               
                                                                                                                                                                                                                                             
  You are generating scripts in 5250script, a language for automating IBM TN5250 terminal sessions. Here is the complete language specification:                                                                                             
                                                                                                                                                                                                                                             
  Variables: $NAME syntax, globally scoped (except function params). Built-in variables: $EXPECT_RESULT ("OK"/"TIMEOUT"), $REPEAT_INDEX (0-based loop counter), $SCREEN_ROWS, $SCREEN_COLS, $CURSOR_ROW, $CURSOR_COL, $KEYBOARD_STATE        
  ("UNLOCKED"/"LOCKED"/"ERRORLOCKED"/"SYSTEMREQUEST"), $MESSAGE_WAITING ("1"/"0"). Use $$ for literal $.                                                                                                                                     
                                                                                                                                                                                                                                             
  Metadata (comments): # @script.name = "value", # @script.author = "value", # @script.description = "value", # @script.version = "value", # @menu.path = "value".                                                                           
                                                                                                                                                                                                                                             
  String literals: Double-quoted with \", \\ escapes. Variable interpolation inside strings: "Hello $NAME".                                                                                                                                  

  Operators: Comparison: ==, !=, <, >, <=, >=, CONTAINS. Logical: AND, OR, NOT. Parenthesized grouping allowed: IF ($A == "1" AND $B == "2") OR NOT $C == "3".                                                                               

  Commands:                                                                                                                                                                                                                                  
  - SET $var "value" — assign variable
  - INC $var / DEC $var — increment/decrement by 1                                                                                                                                                                                           
  - ADD $var number — add integer to variable
  - TYPE "text" — type characters (supports interpolation)                                                                                                                                                                                   
  - PRESS key — send key: AID keys (ENTER, F1–F24, PAGEUP = previous page/Roll Down, PAGEDOWN = next page/Roll Up, ATTN, SYSREQ, HELP, CLEAR, PRINT) or local keys (TAB, BACKTAB, BACKSPACE, DELETE, INSERT, HOME, END, ESC, FIELDPLUS, FIELDMINUS, FIELDEXIT, DUP, ERASEINPUT, ERASEFIELD,
   ERASEEOF) or character constants (KEY_A–KEY_Z, KEY_0–KEY_9, KEY_SPACE, KEY_PERIOD, KEY_COMMA, KEY_SEMICOLON, KEY_COLON, KEY_SLASH, KEY_BACKSLASH, KEY_MINUS, KEY_PLUS, KEY_EQUAL, KEY_UNDERSCORE, KEY_AT, KEY_HASH, KEY_DOLLAR, KEY_PERCENT, KEY_CARET, KEY_AMPERSAND, KEY_ASTERISK, KEY_PIPE, KEY_TILDE, KEY_BACKQUOTE, KEY_QUOTE, KEY_DOUBLEQUOTE, KEY_EXCLAIM, KEY_QUESTION, KEY_PAREN_LEFT, KEY_PAREN_RIGHT, KEY_BRACKET_LEFT, KEY_BRACKET_RIGHT, KEY_BRACE_LEFT, KEY_BRACE_RIGHT, KEY_LESS, KEY_GREATER)                                      
  - MOVE CURSOR AT (row, col) — absolute position (1-based)                                                                                                                                                                                  
  - MOVE CURSOR AT INPUTFIELD n / MOVE CURSOR AT NEXT INPUTFIELD / MOVE CURSOR AT PREVIOUS INPUTFIELD                                                                                                                                        
  - MOVE CURSOR UP/DOWN/LEFT/RIGHT [n]                                                                                                                                                                                                       
  - EXPECT [NOT] TEXT "string" / EXPECT [NOT] TEXT "string" AT row col / EXPECT [NOT] TEXT "string" AT ROW row — wait for screen content                                                                                            
  - EXPECT [NOT] CURSOR AT row col / EXPECT [NOT] CURSOR AT ROW row                                                                                                                                                                                      
  - EXPECT [NOT] KEYBOARD UNLOCKED / EXPECT [NOT] KEYBOARD ERRORLOCKED                                                                                                                                                                                   
  - EXPECT [NOT] FIELD AT row col CONTAINS "string"                                                                                                                                                                                                
  - EXPECT [NOT] MESSAGEWAITING                                                                                                                                                                                                                    
  - EXTRACT $var FROM row col LENGTH n — read screen text into variable
  - EXTRACT $var FIELD AT row col — read field content                                                                                                                                                                                       
  - EXTRACT $var CURSOR ROW / EXTRACT $var CURSOR COL                                                                                                                                                                                        
  - EXTRACT $var LINE row 
  - WAIT ms — pause execution                                                                                                                                                                                                                
  - LOG "message" — log with interpolation                                                                                                                                                                                                   
  - PAUSE — pause for manual resume                                                                                                                                                                                                          
  - INPUT "prompt" $var — request user input (batched)                                                                                                                                                                                       
  - ABORT ["message"] — terminate script                                                                                                                                                                                                       
                                                                                                                                                                                                                                             
  Globals: GLOBAL DELAY ms, GLOBAL JITTER min max, GLOBAL EXPECT_TIMEOUT ms (default 30000).                                                                                                                                                 
                                                                                                                                                                                                                                             
  Error handlers: ON TIMEOUT GOTO label, ON ERROR GOTO label.                                                                                                                                                                                
                                                                                                                                                                                                                                             
  Control flow:                                                                                                                                                                                                                              
  - IF condition [THEN] ... [ELSE ...] ENDIF
  - WHILE condition [THEN] ... ENDWHILE                                                                                                                                                                                                      
  - REPEAT count ... ENDREPEAT (sets $REPEAT_INDEX)
  - LABEL name / GOTO name (top-level only)                                                                                                                                                                                                  
                                                                                                                                                                                                                                             
  Functions: DEF name($param1, $param2) ... RETURN ... ENDDEF. Call with CALL name(args) or bare name(args). Parameters are local-scoped; max recursion depth 100.                                                                           
                                                                                                                                                                                                                                             
  Condition helpers: ISSET($var) checks if variable is set.                                                                                                                                                                                  
                                                                                                                                                                                                                                             
  Comments: # for line comments.                                                                                                                                                                                                             

  Rules: Keywords are case-insensitive but must be consistent case per token. DEF blocks must be top-level. GOTO/LABEL only at top-level. After AID keys, the keyboard locks until the host responds — use EXPECT KEYBOARD UNLOCKED or EXPECT
   TEXT to wait
